# Known Limitations & Platform Boundaries

1. **LinkedIn Direct Profile Writing**: LinkedIn public APIs do not provide self-serve endpoints for modifying personal headlines, About sections, or experiences. All edits are provided as clean copy-paste patch plans to protect member accounts from TOS violations.
2. **Easy Apply Automation**: Automating job submissions violates platform terms. The suite provides tailored talking points, cover notes, and direct URLs for one-click human submission.
3. **Official Posting Token**: Live publishing via the official API requires an active `LINKEDIN_ACCESS_TOKEN` with the `w_member_social` scope.
